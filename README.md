# Endabgabe – Jan Leon

## Projektübersicht

In unserem Projekt „I-Bau-Graffiti“ geht es um die virtuelle Erkundung des I-Baus in Furtwangen, umgesetzt mit A-Frame. Nutzer:innen können sich frei um das digital rekonstruierte Gebäude bewegen und es aus der Luftperspektive betrachten. Zusätzlich stehen drei Szenarien zur Auswahl: „Regen“, „Sonne“ und „Nacht“, jeweils ergänzt durch passende Soundkulissen, die die Atmosphäre der jeweiligen Umgebung stimmungsvoll untermalen.

Über drei schwebende Kugeln lassen sich verschiedene Standorte anwählen, durch die man direkt in oder neben das Gebäude gelangt. Dort hat man die Möglichkeit, die Szenerie in einer interaktiven 360°-Ansicht zu erleben.

An jedem dieser Orte befindet sich eine virtuelle Leinwand (Canva), auf der alle Nutzer:innen zeichnen können – in Echtzeit und kollaborativ, sobald sie dem aufgesetzten Server beitreten.

Das Projekt verbindet immersive Architekturvisualisierung mit kreativem Austausch in einem Mixed-Reality-Kontext.

## Funktionen

- A-Frame Gebäude (I-Bau)
- Anzeige von 360°-Bildern (center, left, right)
- Wiedergabe von verschiedenen Hintergrundgeräuschen (Nacht, Regen, Sonne)
- Benutzerinteraktion über einfache Klicks
- Poster oder Graffiti zum Zeichnen mit Tasten (1,2,3) in den Räumen
- Server von Schnell
- Canva connecten
